# DeFi-and-Smart-Contracts
Uni project on decentralized finance and smart contracts (Solidity).

## Getting started

New to git? Read these in this order:

1. [`docs/git-basics.md`](docs/git-basics.md): what git is + one-time setup
2. [`CONTRIBUTING.md`](CONTRIBUTING.md): how we work (branches, Pull Requests, rules)
3. [`docs/git-cheatsheet.md`](docs/git-cheatsheet.md): commands for daily use

**Short version:** never commit to `main` or `dev` directly. Create a `feature/...` branch from `dev` and open a Pull Request into `dev`.
